Первый публичный выпуск OpenMusic — плеера, который собирает музыку из Spotify, SoundCloud, Deezer, Яндекс Музыки, Apple Music и YouTube по обычной ссылке, без аккаунтов и подписок.

## Что скачать

| Система | Файл | Как запустить |
|---|---|---|
| **Windows 10/11** | `OpenMusic-…-windows-setup.exe` | установщик, права администратора не нужны |
| **Windows**, без установки | `OpenMusic-…-windows-x64.zip` | распаковать и запустить `OpenMusic.exe` |
| **Linux** | `OpenMusic-…-x86_64.AppImage` | `chmod +x` и запустить |
| **Linux**, без AppImage | `OpenMusic-…-linux-x86_64.tar.gz` | распаковать и запустить `OpenMusic/OpenMusic` |

Windows может предупредить, что издатель неизвестен: файл не подписан. Нажмите «Подробнее» → «Выполнить в любом случае».

## Что внутри

- «Мой поток», джемы и миксы из похожих треков
- текст песни в такт и режим «Клип»
- эквалайзер до 31 полосы, 38 пресетов, авто-подстройка, 24 сцены, эффекты
- страница артиста, очередь, плейлисты, «Мне нравится», статистика
- импорт из десяти источников по ссылке или с диска

## Что стоит знать

- **Windows-сборка — первая.** Она собрана и проверена автоматически (запускается, рисует окно, находит и играет трек), но на живом компьютере с Windows её ещё никто не гонял. Если что-то не так — напишите в Issues.
- **Остров** (мини-плеер у края экрана) в этих сборках работает в Windows и в Linux под X11. В Linux под Wayland он есть только при запуске из исходников: нужна системная библиотека layer-shell-qt, которую сборка со своим Qt загрузить не может.
- Звук треков ищется на SoundCloud: там, где SoundCloud недоступен, нужен VPN.
- В Linux для формы звука в плеере и импорта папок нужен `ffmpeg` из репозитория дистрибутива; в Windows он идёт вместе с приложением.
